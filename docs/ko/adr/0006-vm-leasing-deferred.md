# ADR-0006. VM 임대(KubeVirt + PCI 패스스루)는 보류

상태: 보류

## 맥락

"GPU가 붙은 VM을 통째로 빌려주면 어떤가"라는 요구가 있었다. 컨테이너보다 격리가 강하고,
커널 모듈이나 드라이버를 직접 다루는 작업도 가능하다. KubeVirt + PCI 패스스루로 구현할 수
있다.

## 결정

**당분간 하지 않는다.** 제품의 기본 단위는 컨테이너 세션이고, 더 강한 격리가 필요하면
물리 노드 SSH 임대(hybrid 모드)를 옵션 애드온으로 제공한다.

## 이유

- **검증할 환경이 없다.** 개발·검증에 쓰는 랩 자체가 VM 위에 있다. 중첩 가상화와 PCI
  패스스루를 그 위에서 확인할 수 없다.
- PCI 패스스루는 IOMMU 그룹 구성에 민감하다. 컨슈머 GPU는 오디오 기능이 같은 그룹에
  묶이는 등 노드마다 상황이 다르다.
- 노드당 GPU가 1장이면 패스스루로 넘기는 순간 그 노드에서 컨테이너 세션을 못 띄운다.
  자원 활용률이 크게 떨어진다.
- 물리 노드 SSH 임대가 "GPU를 컨테이너 없이 직접 쓰고 싶다"는 요구의 대부분을 이미
  충족한다.

## 다시 검토할 조건

아래가 갖춰지면 재론한다.

- 랩이 아닌 **물리 서버**에서 검증 가능
- IOMMU 그룹이 GPU 단독으로 분리되는 하드웨어
- **노드당 GPU 2장 이상**: 한 장을 넘겨도 노드가 놀지 않도록
- 컨슈머 GPU가 아닌 데이터센터 GPU 또는 패스스루가 검증된 조합

## 결과

- 컨테이너 세션 + 물리 SSH 임대 두 가지로 간다.
- 격리 수준이 컨테이너로 부족한 요구는 물리 임대로 안내한다.
- 이 결정을 기록해 두지 않으면 같은 논의가 반복된다. 그래서 남긴다.
